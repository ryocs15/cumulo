## Değişiklikler

- **Yeni altyapı:** Cumulo baştan yazıldı (C# / WPF, .NET 10). Görünüm ve ayarlar aynı; ayarlarınız, şehirleriniz ve ek widget'larınız olduğu gibi taşınır.
- **Daha az işlemci:** Hareketli kartlar yaklaşık yarı yarıya daha az işlemci kullanır (tam kart, yağmur: ~%40 yerine ~%21, tek çekirdek).
- **Görünmüyorken durur:** Widget'ın üstü kapalıyken, ekran kilitliyken ya da kapalıyken animasyonlar durur ve işlemci kullanımı neredeyse sıfıra iner.
- **Windows ile başlat** artık yeni Windows 11 kurulumlarında da çalışır (eski yöntem kaldırılmakta olan VBScript'e dayanıyordu). Ayar kendiliğinden taşınır.
- **Tepsi ikonu kaldırıldı.** Menü için widget'a sağ tıklayın; widget'ı öne getirmek için kısayol tuşu duruyor.
- Düzeltmeler:
  - Büyütülmüş kartta Türkiye'deki şehirlerin saatlik tahmini 3 saat arayla gösterilir.
  - İngilizce arayüzde şehir araması İngilizce sonuç verir; "Now" sütunu anlık durumun ikonunu gösterir.
  - Hava kalitesi değeri kartta kesilmez.
  - Farklı ölçekli ekranlar arasında taşınan widget doğru boyutta kalır.
  - Bazı yeni Windows kurulumlarında görülen bağlantı (sertifika) hatası giderildi.
- Kurulum dosyası artık **`Cumulo-Setup.exe`** (yaklaşık 48 MB; .NET içindedir, ayrıca bir şey kurmanız gerekmez).
- 64 bit Windows 10 (1809 ve sonrası) ya da Windows 11 gerekir.

## What's new

- **New engine:** Cumulo was rewritten (C# / WPF, .NET 10). It looks and works the same; your settings, cities and extra widgets carry over.
- **Lower CPU use:** animated cards use about half the CPU (full card with rain: ~21% instead of ~40% of one core).
- **Pauses when hidden:** animations stop while the widget is covered, the screen is locked or turned off, so CPU use drops to almost zero.
- **Start with Windows** now also works on new Windows 11 installs (the old method relied on VBScript, which Windows is removing). The setting moves over automatically.
- **The tray icon is gone.** Right-click the widget for the menu; the hotkey still brings the widget forward.
- Fixes:
  - The enlarged card shows 3-hour steps for Turkish cities.
  - In English, city search returns English names and the "Now" column shows the current conditions icon.
  - The air quality value is no longer cut off.
  - The widget keeps the right size when moved between screens with different scaling.
  - Fixed a connection (certificate) error seen on some fresh Windows installs.
- The installer is now **`Cumulo-Setup.exe`** (about 48 MB; .NET is included, nothing else to install).
- Requires 64-bit Windows 10 (1809 or later) or Windows 11.
